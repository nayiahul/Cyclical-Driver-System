## 样本类型（四类）

| 类型 | 定义 | 价值 |
|---|---|---|
| 1 假机会 | 系统看好/人工否定, 后来证伪 | 哪些信号骗人 |
| 2 漏机会 | 系统未发现/后来上涨 | 缺什么变量 |
| 3 正确机会 | 系统发现/兑现 | 哪些信号稳定 |
| **4 判断正确但原因错误** | 结果对了但归因错(如: 涨因库存周期非AI需求) | 防错误经验积累 — 归因错误=最隐蔽污染 |

> 类型4 必须记录: 系统'结论'与'推理链'分离验证。仅当推理链也正确才计为稳定信号。
