## 一、核心定位

**不是**"预测股价的预期差模型"，**而是**"市场认知状态层"。

回答: **市场当前认为这家公司未来会怎样？这种预期是否正被现实数据打破？**

```
Expectation Gap = Actual Business Change − Market Existing Expectation
```

系统缺失的位置:
```
Discovery（变化）→ Lifecycle（阶段）→ L5（错杀）
                                     ↑
                         为什么市场没买账？← 本层
```

## 二、Expectation State 定义（输出不是分数）

| 状态 | 含义 | 典型场景 |
|---|---|---|
| E0 | 市场忽略 | 变化发生，无人关注（RPS 低 + 成交低迷） |
| E1 | 少数资金关注 | 成交放量初现，价格开始试探 |
| E2 | 机构确认 | 趋势形成，RPS 中位 |
| E3 | 一致预期形成 | 全市场讨论，估值扩张 |
| E4 | 预期兑现/透支 | 业绩兑现但股价不涨（利好出尽） |
| E5 | 预期过度 | 估值远超基本面（崩盘前兆） |

**对应关系**: 最佳研究窗口 = 高 Business Change × 低 Expectation（L1×E0/E1）
