# 选股器架构文档

**版本**: v2.0 | **日期**: 2026-05-21 | **目标函数**: 最大化 Calmar (约束: 回撤 ≤ 35%)

---

## 一、系统定位

主动基本面景气策略（非统计套利 Alpha）。允许行业偏离、注重可解释性、Calmar 导向。

## 二、六层漏斗

```
全A股 (~5500)
  → ① 股票池 (universe.py) — 去ST/新股
  → ② 排雷 (valuation_filter.py) — 8条硬约束
  → ③ 因子评分 (signals.py + screener.py) — 景气度×4 + 壁垒×2 + 估值×1
  → ④ Regime (regime/) — BULL/STRUCT/BEAR 动态权重
  → ⑤ 行业约束 + 排序 — 自适应上限 + 拥挤度惩罚
  → ⑥ CSV输出 (均衡Top200 / 拐点Top50)
```

## 三、因子体系

| 维度 | 因子 | 权重 | 说明 |
|------|------|------|------|
| 景气度 | RPS60 | 0.25 | 60日行业内百分位 |
| | 行业动量 | 0.15 | 行业中位数收益 |
| | S1 利润加速度 | 0.30 | 扣非yoy回归斜率>0 + R²>0.6 |
| | S2 产能扩张 | 0.30 | 合同负债TTM yoy + CAPEX yoy |
| 壁垒 | S5 盈利稳定性 | 0.50 | ROE近12季标准差(反向) |
| | S7 现金流质量 | 0.50 | OCF/营收 > 0, 行业内Z-Score |
| 估值 | PE(TTM) 行业内分位 | — | 排名→Z-Score映射 |

S1/S2有效时→四因子合成；无效时→退化为RPS60×0.6+行业动量×0.4。

## 四、Regime 体系

### Market Regime
5维投票 (指数趋势/广度/创新高/风险偏好/流动性) → BULL/STRUCT/BEAR。

| Regime | 景气度 | 壁垒 | 估值 |
|--------|--------|------|------|
| BULL | 0.50 | 0.30 | 0.20 |
| STRUCT | 0.35 | 0.35 | 0.30 |
| BEAR | 0.20 | 0.30 | 0.50 |

STRUCT→BULL 需连续2月确认（滞回）；BULL→STRUCT 立即退回。

### Style Regime（仅诊断）
PE趋势 → GROWTH/VALUE/BLEND，**不参与权重**（v2.0 实验后降级）。

## 六、风控体系

| 层 | 机制 |
|----|------|
| 行业暴露 | BULL≤25% / STRUCT≤15% / BEAR≤10% + 拥挤度>20%→×0.85 |
| 换手惩罚 | 现有持仓 composite×1.03，降低不必要换手 |
| 得分加权 | composite分位归一化到[0.5,1.5]做权重倾斜 |
| 流动性上限 | 日均成交<5000万→单票上限4% |
| 回撤预算 | 正常<15% / 预警15-25% / 临界>25% 三层响应 |

## 七、数据治理

| 机制 | 说明 |
|------|------|
| 披露截止日 | TDX 用法定截止日(优先实际日历)，AKShare 用法定截止日 |
| 披露日历 | westock-data InfoPublDate，5508只已缓存 |
