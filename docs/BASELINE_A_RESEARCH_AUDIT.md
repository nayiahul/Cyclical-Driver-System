## 4. 初步结论（污染状态画像，非投资结论）

1. **系统当前本质是动量系统**：RPS 中位 72、74.6% 买入无变化信号、37% 无 S1/S2 → composite 中 momentum fallback 到 `RPS*0.6 + 行业动量*0.4` 时纯动量主导
2. **S1/S2 覆盖率是核心问题**：仅 7%/20% 股票有信号 → "周期驱动"因子实际参与度低
3. **H1 认知差假设在污染样本内不成立**：Confirmed > Early Discovery——但被 RPS 未来函数污染，需 PIT 后重验
4. **收益结构**：61% 胜率、收益分散（>50% 仅 20 只）、亏损受权重约束（<-20% 仅 14 只）

**对后续的指导**：
- PIT 修复后必须重跑本分析（B 状态）——若 H1 仍不成立，系统定位应调整为"趋势确认 + 质量过滤"，而非"早期认知差探测"
- 若希望系统真正捕捉 L1 变化萌芽，需要提高 S1/S2 覆盖率（当前 93%/80% 无信号）——这可能是信号定义过严（R²>0.6）或数据质量问题
