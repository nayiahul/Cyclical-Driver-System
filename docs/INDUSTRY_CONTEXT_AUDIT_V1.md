# Industry Context Layer v1 — 历史验证负结果（冻结）

**日期**: 2026-09-02
**状态**: v1（财务聚合版）**淘汰冻结**；L5 v1 维持正式能力不受影响
**结论**: 财务中位数行业层无增量信息（方向可能正确，构建方式错误）

---

## 一、验证结果（2022-2025, 1539 L5 事件）

| Group | n | 恢复率 | 失败率 | fwd6 |
|---|---|---|---|---|
| A 全部 L5（基线） | 1539 | 50.2% | 12.7% | +8.8% |
| B Industry GREEN | 931 | 49.8% | 15.4% | +4.6% |

```
H1 (GREEN 提高恢复率): ❌ 49.8% < 50.2%
H2 (RED 识别陷阱):     ❌ RED 组为空, 无法检验
```

## 二、失败归因（拆清"缺数据" vs "缺变量"）

### 1. 财务是滞后变量，行业财务中位数在 L5 窗口内天然最钝
```
商品价格变化 → 企业库存调整 → 售价 → 收入 → 利润（滞后 2-4 季度）
L5 判断窗口（价格已跌、财报还绿）恰是行业财务最弱的时候
```

### 2. RED 组为空的直接原因
行业财务中位数极少达到阈值（profit_yoy<-5% / loss_rate>50%）——季度数据 + 中位数平均双重钝化

### 3. 融捷案例未被识别（关键实证）
```
002192 融捷股份: gate=YELLOW（预期 RED）
原因: 缺商品价格（锂价）数据 — 财务中位数被有色板块其他品种稀释
```

### 4. YELLOW > GREEN 的反直觉结果
v1 粗糙定义下"行业一般"反而更好 → 财务+RPS 构建的行业状态与恢复结果的关系是噪声

## 三、结论

1. **Industry Context 方向未否定**——但 v1 构建方式（财务聚合代理）无法提供增量
2. **缺的不是更多财务数据，是产业周期变量**（价格/库存/销量/开工率）
3. L5 v1（恢复率 50.2%、错误率 8.7%）维持正式能力
