## 一、结果

## 二、结论

1. **H-E1 成立**: L1×E0/E1 升级率 53%+ > 基线 47.5%（+6pp）
2. **E2 是陷阱区**: L1 但市场已关注 → 升级率 15.3%、fwd6 -2.0%、失败率 27.2%
   ——"变化未确认"与"市场已关注"冲突时，后者胜（故事已定价）
3. E0x（负面冲击）v0 定义在 L1 内无样本 → 需真实数据细化（shock 代理仅对 discovery≥0.5 有效）

## 三、Lifecycle v3 修正

```
L1 × E0/E1 → A 级研究（预期差窗口）
L1 × E2   → C 级（市场已定价, 降级）
```

**E 状态是 L1 内部的分层器**（不是所有 L1 都值得 A 级）——修正此前 state_machine 的 L1 一律 A 的规则。

## 四、限制

- E 状态 v0 仅用 RPS 代理价格关注；真实关注度（成交额 Z）未纳入
- shock 代理需细化（用单季 yoy 加速度替代探针组合）
- 未做 Train/Test 分离（先用全样本确认方向）
