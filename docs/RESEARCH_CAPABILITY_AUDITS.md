# Research Capability Audits — 研究能力五审计（设计 v1）

**状态**: 设计冻结（2026-09-01），数据依赖 12 采样日扩展样本
**定位**: 证明"价值重估早期发现能力"，非策略收益优化

---

## 一、五个实验与对应问题

| # | 审计 | 核心问题 | 证明什么 | 数据 |
|---|---|---|---|---|
| 1 | OOS Audit | 规律是否稳定？ | 非偶然样本 | 扩展样本分年度 |
| 2 | State Transition Audit | 是否抓住变化过程？ | 生命周期价值 | 相邻采样日配对 |
| 3 | Lead Time Audit | 是否真的领先？ | 时间优势 | Discovery vs RPS 时序 |
| 4 | Winner Capture Audit | 能否找到大机会？ | 研究池质量 | L1 池涨幅分位 |
| 5 | False Positive Audit | 能否排除错误？ | 误判控制 | L1 失败案例归因 |

## 二、Lead Time Audit（严格定义）

领先 = 市场确认时间 − 经营变化时间，两个独立事件：

```
Event A (T0): 经营变化出现 = 探针首次 green（订单/CAPEX/毛利）
Event B (T1): 市场确认 = RPS 首次进入高分位（≥70）或 L2 状态
Lead Time = T1 − T0（季度级，采样日间隔）
```

粗粒度版本（现有数据）：
- 每只股票跨采样日追踪，首次 L1 采样日（≈T0 已发生）
- 首次进入 L2/L3 的采样日（≈T1）
- 输出: 领先季度分布（中位/均值/25%/75%）

**验收**: 中位领先 ≥ 1 个采样周期（~4 个月），且 > 0 比例 ≥ 60%

## 三、Transition Audit（含 Hit Rate）

| 迁移 | 定义 | 指标 |
|---|---|---|
| L0→L1 | 首次发现 | fwd6 + **Hit Rate（fwd12 涨幅>30% 比例）** |
| L1→L1 | 持续改善 | 同上 |
| L1→L2 | 市场确认 | 同上 |
| L2→L3 | 拥挤 | 同上 |

**验收**: L0→L1 Hit Rate > L0→L0 Hit Rate，且 fwd6 收益 L0→L1 > L1→L1（抓的是转折）

## 四、Winner Capture Audit（赔率视角）

```
Capture Ratio = L1 池未来进入全市场涨幅 TOP10% 的比例 / 10%
翻倍概率 = L1 池 fwd12 涨幅 > +100% 比例 vs 全市场基准
```

输出: Top10% 捕获率 / +50% 概率 / +100% 概率 / 3 倍概率

**验收**: Capture Ratio > 1.3（即 L1 池抓到 TOP10% 赢家的概率比随机高 30%+）

## 五、False Positive Audit（误判归因）

对 L1 后 fwd6 < -20% 的样本分类：

| 类别 | 定义 |
|---|---|
| 需求未兑现 | 订单领先信号后营收未跟随 |
| 周期反转 | 毛利/CAPEX 信号后价格周期逆转 |
| 估值陷阱 | 低 RPS 但基本面恶化确认 |
| 财务质量 | 现金流/盈利质量恶化 |
| 主题炒作 | 信号来自一次性因素 |

输出: 各失败类别占比 + 可预防比例（探针 red 是否本可预警）

**验收**: 失败样本中 ≥30% 存在"探针早已转 red"的可预防信号 → 状态机可加入退出规则

## 六、能力边界声明（全部通过后）

可以：
- ✅ 5000 → 20-50 研究对象压缩
- ✅ 识别可能正在变化的公司
- ✅ 判断价值重估阶段
- ✅ 提供人工深研优先级

不能：
- ❌ 自动预测股价
- ❌ 替代投资经理判断
- ❌ 消除周期风险
