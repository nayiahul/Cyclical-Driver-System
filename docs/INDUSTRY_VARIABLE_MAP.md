# Industry Variable Map v1 — 行业变量字典（Step 8.3）

**日期**: 2026-09-02
**状态**: 变量映射冻结 + 数据源可行性确认
**依据**: Industry Context v1 负结果归因（缺的是产业周期变量，非更多财务数据）

---

## 一、核心原则（从 v1 负结果提炼）

1. **公司财务是滞后变量**（滞后商品价格 2-4 季度）→ 行业层必须用**前瞻变量**
2. **行业财务中位数天然最钝**（季度 + 中位数双重平均）→ 弃用
3. **行业状态 = 价格/销量/供需**，公司状态 = 财务（二者时间尺度不同）

## 三、L5 v2 行业层设计（重构版）

```
L5 Candidate（公司层不变）
    ↓
Industry Signal（前瞻变量，非财务）:
  ┌─────────────────────────────────┐
  │ 商品价格趋势（3/6 个月动量）       │ ← 最高优先 (价格领先财务)
  │ 行业指数动量（申万行业 RPS）       │ ← 可 PIT 构建
  │ 库存/供需（若有）                │ ← v1.1
  └─────────────────────────────────┘
    ↓
Gate:
  价格↑ + 行业RPS↑  → L5-A（恢复确认）
  价格↓ + 行业RPS↓  → Recovery Trap（降级）
  混合              → L5-B
```

## 四、验证优先序（Step 8.4）

| 优先级 | 行业 | 案例锚点 | 数据就绪度 |
|---|---|---|---|
| 1 | **锂矿** | 002192 融捷（人工分歧样本） | ✅ LC0 已可拉取 |
| 2 | **工程机械** | 000425 徐工（行业确认缺口） | ⚠️ 销量需手工源 |

**锂矿先行理由**：融捷是 Calibration Prototype 唯一 MODEL_DISAGREEMENT 样本，用其验证"锂价 3 个月动量能否把融捷从 L5-A 降为 Trap"是最直接的检验。
