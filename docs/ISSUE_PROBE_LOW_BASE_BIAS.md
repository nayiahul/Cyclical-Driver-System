# Issue: Discovery 探针低基数偏差（L1 Probe Low Base Bias）

**发现日期**: 2026-09-02（人工复核 600276 恒瑞触发）
**类型**: Discovery 层定义缺陷——同比增速在低基数下制造虚假拐点
**与 E 层 Issue 的区别**: 300308 是"市场状态判断错误"，恒瑞是"企业变化判断错误"——不同层级

---

## 一、错误案例（600276 恒瑞医药）

| 指标 | 系统视角 | 实际数据 |
|---|---|---|
| 合同负债 | "+371%（订单爆发→L1）" | 9.5亿 vs 前季14.5亿（**环比-35%**） |
| 营收 yoy | — | +13% → **-2%（转负）** |
| 扣非 yoy | — | **-13%（恶化）** |

**根因**: 同比增速无低基数过滤——去年同期基数极低时，小金额增长显示巨大百分比。

## 二、Discovery 层缺少的三个防误报门槛（L1 v2 候选）

### 1. Absolute Scale Gate（绝对规模）
- 现状: 只看 `YoY > 50%`
- 增加: 合同负债绝对额 / 营收占比 或 新增额 > 历史波动范围

### 2. Sequential Confirmation（环比确认）
- 现状: `YoY ↑` 即信号
- 增加: `YoY ↑ 且 QoQ ↑` 才算强信号（恒瑞: YoY↑但QoQ↓ = 弱信号）

### 3. Earnings Quality Gate（利润质量）
- 现状: L1 只看订单/CAPEX/毛利
- 增加: 营收趋势 + 扣非趋势 + 现金流（防"订单指标绿, 利润红"）

## 三、影响范围

- 所有依赖 tdx 同比字段的探针（合同负债/revenue_yoy 等）
- 300308 同源问题: 合同负债+121% 但绝对值仅 0.2亿（光模块行业订单不走预收, 需行业口径）
