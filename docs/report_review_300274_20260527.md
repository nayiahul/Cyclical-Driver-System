## 已完成修复（3项）

### 1. g* 可信度检验

**问题**：g*=80%（EWA历史外推）但营收增速=-18.3%，PEG=0.3极低但不可信。

**修复**：`funnel.py` _score_l5 增加可信度校验：
- 符号背离：g*>10% 且营收<-5% → 不可信
- 高估背离：g* - 营收增速 > 30pp → 不可信（g*远高于实际）
- 不可信时：PEG得分×0.5，标签追加"⚠️ g*与近期增速背离"

**效果**：
- 阳光电源 PEG: 4.0 → 2.8(谨慎折扣) → 1.4(可信度折扣)
- 旭创不受影响（g*=80% < 实际192%，保守估计，可信）

### 2. 决策卡片风险汇总

**问题**：报告显示"未发现明显风险因素"，但下方有 ROIC<WACC 和 应收飙升 红色/黄色卖出信号。

**修复**：`report.py` 风险列表增加：
- PEG g*可信度低标记
- ROIC<WACC（L3详情）
- L1排雷标记（条件红灯）
- 卖出信号（red/yellow level）

**效果**：
- 阳光电源风险栏现在显示 4 条具体风险：PEG可信度低、ROIC毁灭价值、排雷警告、ROIC跌破WACC

### 3. PEG_CONFIDENCE 新增逆变器行业

**问题**：逆变器不在 PEG_CONFIDENCE 中，使用"通用框架"默认。

**修复**：`config.py` 新增：
```python
"逆变器": {"level": "caution", "driver": "周期价格型",
           "note": "PEG需谨慎：光伏产业链周期敏感，增速波动大"}
```
