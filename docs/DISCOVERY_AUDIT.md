### H2 正交假设：✅ 成立（弱）

```
Discovery高 + RPS低 : +1.6% (n=1004)
Discovery低 + RPS低 : -0.5% (n=1667)
增量: +2.1pp
```

**关键形态**:
- Discovery 的预测力**集中在 RPS 低分组**（+2.1pp 增量）
- RPS 高分组中 Discovery 无增益（-1.6% vs -2.7%）→ 高 RPS 时预期差已消失
- **企业变化领先于价格表现**——正是"周期预期差"的形态

## 四、结论与限制

### 结论
1. Discovery 不是趋势的重新包装（正交性成立）
2. Discovery 的价值 = **在 Confirmation 之前识别"尚未被市场确认的变化"**
3. 架构方向：**不是评分因子，而是"机会状态识别层"**（L0-L5 状态机）

### 限制（不能过度解读）
1. **+2.1pp 是弱信号，不是 Alpha**——需更长周期/多市场环境/行业拆分验证
2. 采样窗口 2022-2023（熊市+震荡），未覆盖 2024-2025 牛市
3. 收益为等权平均，未做风险调整
4. 探针 4（客户集中度 PDF）未纳入（数据覆盖有限）

## 五、架构决策（本审计的直接输出）

```
Discovery 高 + RPS 低 → L1 Early Discovery（研究优先级最高）
Discovery 高 + RPS 中 → L2 Inflection Confirmation
Discovery 高 + RPS 高 → L3 Market Confirmed（预期差消失，降低优先级）
Discovery 低          → L0 No Change（忽略）
```

**不做权重相加**——三个引擎回答不同问题，用状态机组织（见 INVESTMENT_STATE_MODEL.md）。
