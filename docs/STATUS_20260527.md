日期：20260527 | 版本：v2.1.x 封版

## 系统架构

```
全A股 ~5000只
  → 预过滤器 (L1基础清洗 → L2成长信号门 → 优先级排序)
  → 六层漏斗
      L1 排雷 (8项检查 + 利润质量归因 + 应收相对增速)
      L2 护城河 (毛利率/费用率/研发/合同负债/营收加速度)
      L3 资本效率 (ROIC vs WACC + 趋势 + 增量ROIC)
      L4 行业校准 (5指标行业分位 + 绝对底线约束 + 赛道排名)
      L5 预期差 (PEG + g*可信度 + 框架路由 + PE分位)
  → 成长资格门 (ROIC<WACC且营收负→周期跟踪)
  → 三项并行评估
      周期位置评估 (FCF/订单/债务/库存)
      CAPEX周期定位 (扩张/危险/收缩/复苏/平台)
      卖出信号检测
  → 综合评分 + 决策卡片 + 报告输出
```

## 探针体系（6项，均不参与综合评分）

| # | 探针 | 数据源 | 输出 |
|---|------|--------|------|
| 1 | 订单领先性 | 合同负债季度序列 | 🟢需求漏斗/🟡同步/🔴萎缩 |
| 2 | CAPEX效率 | CAPEX+ROIC季度序列 | 🟢健康扩产/🟡扩张期/🔴激进 |
| 3 | 毛利率韧性 | 毛利率季度序列 | 🟢强定价权/🟡正常/🔴承压 |
| 4 | 客户集中度 | PDF年报(自动下载+提取) | 🟢分散/🟡集中/🔴高度集中 |
| 5 | CAPEX周期 | CAPEX+营收季度序列 | 扩张/危险/收缩/复苏/平台 |
| 6 | 利润质量归因 | 四费+减值+扣非 | 费用刚性/减值拖累/非经常性桥 |

## 关键设计决策

- **预过滤器**：排除法(砍不可能) + 多路径OR(不杀异类) + 全行业分位(非绝对值)
- **成长资格门**：ROIC<WACC且营收负→剥夺成长身份，降为周期跟踪
- **g*可信度**：EWA外推与近期增速背离时打折+标签警告
- **ROIC趋势条件**：ROIC<WACC时趋势分×0.3，"改善但意义有限"
- **L4绝对底线**：ROIC<WACC时行业分位×0.7，"行业都烂≠你好"
- **PEG框架路由**：周期/出清态→⛔框架不适用；技术扩散→✅有效
- **应收双轨判断**：正增长用倍数法，负增长用偏离法
- **探针准确率**：历史回测13季×80样本，发现3G0R=-9.6%(反向指标)
