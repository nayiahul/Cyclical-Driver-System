## 系统架构

```
全A股 ~5000只
  → 预过滤器 (基础清洗 → 成长信号门(4路径OR) → 优先级排序)
  → 六层漏斗
      L1 排雷 (8项 + 利润质量归因 + 应收双轨判断)
      L2 护城河 (毛利率/费用率/研发/合同负债/营收加速度)
      L3 资本效率 (ROIC(单季)vsWACC + 趋势(年度TTM) + 单季异常)
      L4 行业校准 (5指标行业分位 + 绝对底线约束 + 赛道排名)
      L5 预期差 (PEG±g*可信度 + 框架路由 + PE分位)
  → 成长资格门 (ROIC<WACC且营收负 → 周期跟踪)
  → 三项并行评估
      周期位置 (FCF/合同负债/债务/库存)
      CAPEX周期 (扩张/危险/收缩/复苏/出清滞后/平台)
      卖出信号
  → 综合评分 + 决策卡片 + 报告输出
```

## 探针体系（6项，均不参与综合评分）

| # | 探针 | 数据源 | 输出 |
|---|------|--------|------|
| 1 | 订单领先性 | 合同负债季度序列 | 🟢需求漏斗/🟢高增长/🟡同步/🔴萎缩 |
| 2 | CAPEX效率 | CAPEX+ROIC季度序列 | 🟢健康扩产/🟡扩张/🔴激进 |
| 3 | 毛利率韧性 | 毛利率季度序列 | 🟢强定价权/🟡正常/🔴承压 |
| 4 | 客户集中度 | PDF年报(自动下载+提取) | 🟢分散/🟡集中/🔴高度集中 |
| 5 | CAPEX周期 | CAPEX+营收季度序列 | 6种状态(含出清滞后) |
| 6 | 利润质量归因 | 四费+减值+扣非 | 费用刚性/减值拖累/非经常性桥 |

## 关键设计决策

- **预过滤器**: 排除法(砍不可能) + 多路径OR(不杀异类) + 全行业分位(非绝对值)
- **成长资格门**: ROIC<WACC且营收负 → 周期跟踪(非成长持仓)
- **g*可信度**: EWA外推与近期增速背离时打折+标签警告
- **ROIC趋势条件**: ROIC<WACC时趋势分×0.3
- **L4绝对底线**: ROIC<WACC时行业分位×0.7
- **PEG框架路由**: 周期/出清态→⛔框架不适用(score=0)；技术扩散→✅有效
- **应收双轨判断**: 正增长用倍数法，负增长用偏离法
- **ROIC口径对照**: 单季快照=决策依据(领先)，年度TTM=趋势参考(滞后)
- **探针准确率**: 13季×80样本回测，发现3G0R=-9.6%(反向指标)
- **非成长持仓措辞**: "优势"→"市场状态"，仓位定性约束(不超组合1/3)
