# Issue: Event Layer Missing — 系统缺少"市场叙事变化感知层"

**发现日期**: 2026-09-02（300308 FCC 禁令事件触发）
**层级**: 架构级——L/E/P 三轴均无法发现"市场为什么改变看法"
**状态**: Issue 记录 + X v1 设计冻结 → T+30 评估是否进入 v4.0

---

## 一、问题案例（300308 中际旭创）

系统看到: L1(强变化) × E(回调) × P(AI光模块) → 误判倾向"预期差机会"

系统没看到:
```
8/4  FCC 拟禁中国光模块 (政策风险, 股价 -16%)
7/29 1.6T 降价传闻 (盈利预期冲击)
7/11 Meta 出租算力 → AI Capex ROI 争议 (板块估值)
8/31 40-80亿回购 + 半年报净利+241.7% (对冲信号)
```

**危险误判**: "基本面变好 + 股价下跌 = 预期差" vs 真实"市场提前交易未来风险"——投资含义相反。

## 二、根因

- 财务数据 (L/P) 是滞后的: 政策/价格传闻/叙事变化永远无法从财报发现
- akshare 个股新闻不覆盖外媒政策事件 (FCC 经 Reuters 首发)
- E 层只回答"市场知道多少", 不回答"市场为什么改变看法"

## 三、X v1 设计（Event Intelligence 事件层 — 冻结草案）

### X 回答的问题
> 最近 60-90 天，市场为什么重新定价？

### 五类事件 (X1-X5)

| 类 | 内容 | 案例 (300308) | 方向 |
|---|---|---|---|
| X1 公司事件 | 财报/电话会/回购/增减持/合同 | 40-80亿回购 (8/31) | 正面 |
| X2 行业事件 | 价格/技术切换/竞争 | 1.6T降价传闻 (7/29) | 负面 |
| X3 政策事件 | 制裁/出口管制/FCC/关税 (必须独立: 财务永远发现不了) | FCC拟禁中国光模块 (8/4) | 负面 |
| X4 宏观资金 | AI ROI 争议/利率/风格 | Meta出租算力 → capex质疑 (7/11) | 负面 |
| X5 竞争事件 | 对手产能/生态变化 | 新易盛/天孚扩产 | 双向 |

### Event Card 三要素 (防噪声规则)
1. **必须影响盈利预期** (非董事长讲话/日常新闻)
2. **必须记录方向**: 正面/中性/负面
3. **必须记录验证条件**: 如 FCC "若只限新型号→影响低; 若全面限制→影响高"

### 事件时间轴 (核心输出)
```
日期      事件              市场反应
7/11     AI ROI 担忧        ↓
7/29     1.6T 降价传闻      ↓↓
8/4      FCC 政策风险       ↓↓↓   ← 主导定价事件
8/31     回购+半年报         ↑
```
判断: 当前价格在交易哪个事件?

### 三条防污染规则
1. 事件必须影响盈利预期
2. 必须记录方向
3. 必须记录验证条件
(X 层不自动评分 — 延续 RPI 教训)

## 四、与 E 层的关系（修复闭环）

```
E: 市场知道多少 (状态)
X: 为什么重新定价 (原因)
组合 = 完整认知: "高关注回调 + FCC 政策驱动" ≠ "高关注回调 + 估值消化"
```
