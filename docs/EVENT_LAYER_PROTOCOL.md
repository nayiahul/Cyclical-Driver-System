# Event Layer Protocol v1 — 信息流层协议（冻结）

**日期**: 2026-09-02（Step 13）
**定位**: X = Information Flow Layer（信息流层）——回答"市场现在正在交易什么"
**原则**: 采集自动化 + 影响人工评估。X 不进入 L/E/P 任何自动评分（防主题投资）
**时间结构**: 财报真空期（中报→三季报）是 X 层主战场——财务不变，资讯是最大变量

---

## 一、为什么需要 X 层（时间维度缺失）

```
A股基本面系统的时间结构（当前缺陷）:
财报(8/31) ──── 真空期: 系统只看到价格 ──── 财报(10/31)
                      ↑
                市场在交易资讯流, 系统在"失明"

市场真实定价过程 = 财务数据(低频) + 资讯数据(高频) + 价格数据(实时)
```

## 二、进入系统的事件标准（防噪声第一规则）

### ✅ 进入（必须影响盈利预期或估值假设）
- X1 公司: 回购/增持/减持、业绩预告/快报、重大合同/订单、股权激励、澄清
- X2 产业: 产品价格变化、技术切换(800G→1.6T)、产能/竞争格局
- X3 政策: 制裁/出口管制/FCC/关税/监管（**必须独立: 财务永远发现不了**）
- X4 上下游: 产业链传导（GPU/HBM→光模块→PCB→电力）
- X5 市场认知: 机构报告、一致预期变化、大资金/ETF 流向（E×X 交叉）

### ❌ 排除
- 董事长讲话/日常经营新闻（无盈利预期影响）
- 重复新闻/旧闻炒作/无来源传闻
- 单一机构观点（除非影响一致预期）

## 三、事件影响链（核心格式 — 不是新闻列表）

```
事件: FCC 拟限制中国光模块 (8/4)
  ↓
影响对象: 300308/300502/002281 (光模块板块)
  ↓
影响变量: 北美收入风险敞口
  ↓
方向: 负面 | 程度: HIGH
  ↓
验证: ①正式文本范围(新机型?) ②海外产能比例 ③客户认证
```

## 五、每日流程（真空期）

```
每日采集器 (自动):
  akshare 公告 (Top50 + Shadow 池)
  akshare 个股新闻 + 财联社快讯 (行业词库)
  AnySearch 政策/行业检索 (关键词, 行业词库)
  → data/events/{date}_events.jsonl

每日 Book:
  Market Intelligence Brief 区:
    每只 DEEP 标的: 过去30天重大事件 (正面/负面/待验证)
    + 事件支持度: 财报 thesis 是否被事件增强/削弱

每周简报 (人工确认):
  事件→价格关联表 (哪类事件引发持续反应)
```

## 六、事件支持度定义（v1 简化，人工确认）

```
Thesis 增强: 事件正面 + 方向一致 (如 回购+订单)
Thesis 削弱: 事件负面 + 验证风险高 (如 FCC+降价)
待验证: 传闻/草案 (方向已知, 程度未知)
```

## 七、防污染规则（不重蹈 RPI）

1. X 不进入自动评分/状态机
2. 采集自动, 影响判断人工 (Rule 4)
3. 事件只解释"为什么现在变化", 不改变 L/E/P 本身
4. 30 天数据积累后才有权设计 X v1 影响模型

## 八、数据积累目标（30 天）

- 1000+ 条事件 (分类标注)
- Top50 × 30 天事件-价格关联
- 人工确认哪些事件类别真正影响股价 → X v1 设计依据
