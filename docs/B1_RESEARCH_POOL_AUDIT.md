## 三、关键发现

1. **未来函数偏爱"小市值通信/有色"**：消失的 73 只中通信 15 只、33% <50 亿——小票 RPS 更易被未来价虚高
2. **PIT 后转向"医药/电新 + 中大盘"**：新进的 73 只中位 110 亿，小市值占比仅 10%
3. **保留的 27 只是最稳健核心**：电子/银行 + 中位 138 亿——真趋势（非泄漏趋势）
4. **市值自动迁移**：<50 亿占比 26% → 9%——PIT 后研究池更"可研究"（流动性/信息覆盖更好）

## 四、研究视角结论（非收益视角）

- 收益：+132.4% → +11.7%（-120.7pp，其中含价格泄漏 + 规则恢复两因素，待 A1 拆分）
- **研究池质量：正向变化**——池子从"小市值高波动（未来函数虚高）"变为"中大盘真实趋势"
- 对你的目标（5000→50 研究池）：PIT 后的池子**更可信、更可研究**

## 五、待 A1 baseline 完成后的拆分

```
A  (污染)      → 旧系统
A1 (价格PIT)   → 价格泄漏贡献（= A - A1）
B1 (价格+规则) → 功能恢复贡献（= A1 - B1）
```
