# L5 Mispricing Recovery Model v1 — 错杀恢复引擎设计

**状态**: 研究设计（2026-09-01）— **先固化假设与验证协议，后实现**
**证据基础**: State Transition Audit 发现 L3→L1 迁移 fwd6 = +11.4%（n=1662，全表最高）
**关键区分**: 该证据是**事后状态描述**，本设计目标是升级为**事前机会识别器**

---

## 一、核心假设

> 当市场关注度下降导致价格回撤，但企业经营质量和周期逻辑未破坏时，存在估值修复机会。

```
L5 = Business Intact（企业没坏） + Market Damaged（价格坏了）
```

形式化：
```
L5 机会 = 过去被市场确认（L2/L3 历史）
       ∩ 价格错误杀跌（跌幅/估值压缩/RPS 下降）
       ∩ 基本面未破坏（探针非 red + 盈利未恶化）
       ∩ 行业未进入衰退
```

## 二、三层判定框架

### Layer 1：过去曾被市场确认（防"普通下跌股"冒充）
| 条件 | 数据 | 说明 |
|---|---|---|
| 历史状态 ∈ {L2, L3} | 状态序列（采样日） | 市场曾给过估值 |
| 或 RPS 曾 ≥ 70 | RPS 历史 | 曾被关注 |
| 或 行业/主题曾强 | 行业 RPS 历史 | 板块曾认可 |

### Layer 2：价格发生错误杀跌
| 条件 | 数据 | 说明 |
|---|---|---|
| 前期上涨后急跌：60日收益 >+20% → 后续 60日 < -20% | 价格（PIT as_of） | 上涨→急跌形态 |
| 估值压缩：PE 历史分位 >70% → <40% | PE 分位 | 主要杀估值（vs 杀业绩） |
| RPS 显著下降：>80 → <50 | RPS | 市场关注消退 |

### Layer 3：基本面未破坏（最关键，L5 与普通下跌股的分水岭）
| 条件 | 数据 | 说明 |
|---|---|---|
| 订单探针 ≠ red | growth_probes | 合同负债未恶化 |
| CAPEX 探针 ≠ red | growth_probes | 扩产逻辑未破坏 |
| 毛利探针 ≠ red | growth_probes | 定价权未丧失 |
| 收入 YoY > 0 | 财务（PIT） | 盈利趋势未断 |
| 行业未确认衰退 | 范式/行业状态 | 周期顶部确认则排除 |

> False Positive Audit 的启示：33% 失败样本有 red 探针——Layer 3 正是反向过滤器。

## 三、输出定义

```json
{
  "code": "xxxxxx",
  "state": "L5",
  "priority": "A",
  "reason": "市场关注下降（RPS 85→42），但订单/CAPEX/毛利探针均未恶化，估值压缩 72%→35% 分位，存在估值修复可能",
  "risk": ["行业周期若确认顶部则信号失效", "回撤可能继续（基本面恶化滞后显现）"],
  "recovery_proxy": "历史 L3→L1 样本 fwd6 +11.4%"
}
```

## 四、验证协议（关键：Train/Test 分离）

**禁止用 Transition Audit 的 L3→L1 样本既当发现又当验证。**

| 阶段 | 窗口 | 用途 |
|---|---|---|
| Train | 2022-2023 | 确定参数：跌幅阈值（20/30/40%）、RPS 下降幅度、估值压缩幅度 |
| Test | 2024-2025 | **独立验证**（参数不调整） |

### 验收指标（Test 期）

| # | 指标 | 目标 | 说明 |
|---|---|---|---|
| 1 | L5 vs L0 超额收益（fwd6） | L5-L0 > **5%** | 训练期 L3→L1 是 +11.4%，OOS 打折后定 5% |
| 2 | 胜率 | > **55%** | |
| 3 | 错误率（基本面已坏却进 L5） | < **15%** | 事后核查：进入 L5 后 2 期内容收入/利润是否确认恶化 |
| 4 | **恢复概率**（核心） | > **50%** | 进入 L5 后 6 个月内重新进入 L2/L3（市场认知恢复）——L5 逻辑是恢复认知，不是赌上涨 |

### 行业拆分
- 周期制造：预期 L5 最有效（范式支持）
- tech_growth：观察（错杀形态可能不同）
- 防御：可能无效（低波动）

## 五、与 Lifecycle 的关系

```
         L4（兑现/透支）
          ↑
L1 → L2 → L3
↑          |
|          ↓
└──── L5 ←─┘（错杀恢复：重新进入机会）
```

L5 不是终点，是"市场错误定价后的重新进入机会"。恢复后可回到 L2（确认中）。

## 七、失败标准（可证伪）

- Test 期 L5-L0 ≤ 5% 或恢复概率 ≤ 50% → L5 假设在 OOS 不成立 → 降级为"观察标签"（不进入研究池排序）
- 错误率 > 15% → Layer 3 基本面过滤不足 → 需加强（加入现金流/毛利趋势确认）

## 八、约束（延续方法论）

1. 零评分影响：L5 只做标签，不改 composite/state_machine 现有逻辑
2. 参数只在 Train 期确定，Test 期冻结
3. 每次只改一个变量（归因隔离）
