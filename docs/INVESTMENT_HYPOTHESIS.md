# Investment Hypothesis Framework — 投资假设框架

**状态**: 研究假设（2026-09-01 确立 + 三引擎架构校准）— 未经 Phase 2 实证验证前，**不编码为评分公式**
**定位**: 系统的第一性原理。先提出假设 → 数据验证 → 确定有效维度 → 再设计评分体系

---

## 〇、三引擎架构（2026-09-01 共识：不是二选一）

> **趋势确认与周期预期差不是竞争关系，而是投资决策链的前后两个环节。**

```
5000 家公司
    ↓
Discovery Engine（发现变化）—— 需要加强
    ↓
Confirmation Engine（市场确认）—— 当前已强（Baseline A 证实）
    ↓
Valuation Engine（估值约束）—— 已有
    ↓
人工深度研究 → 投资备忘录
```

| 引擎 | 回答的问题 | 组成 | 当前状态 |
|---|---|---|---|
| **Discovery** | 哪里正在发生重要变化？ | 周期变化（库存/价格/供需）+ 经营拐点（收入/毛利/订单）+ 结构优势（ROIC/现金流） | **弱**（S1>0 仅 7%，S2>0 仅 20%） |
| **Confirmation** | 市场是否开始验证？ | RPS + 行业强度 + 成交/资金 | **强**（RPS 中位 72，52% >70） |
| **Valuation** | 是否还有空间？ | PE 分位 + PEG + 同业比较 | 强（71% 买入 PE<30） |

**Baseline A 审计的核心发现**: 当前系统实际运行在"Discovery 弱 × Confirmation 强 × Valuation 中"区域——
擅长找到已经开始上涨的周期股，不擅长找到刚发生变化但市场未发现的标的。

**决策链展示（三维状态而非单分数）**:

| 状态 | Discovery | Confirmation | Valuation | 含义 |
|---|---|---|---|---|
| 早期机会 | ★★★★★ | ★★★ | ★★★★ | 值得研究 |
| 趋势确认 | ★★★★ | ★★★★★ | ★★ | 可交易但研究估值 |
| 风险区域 | ★★ | ★★★★★ | ★ | 已充分定价 |

## 一、系统寻找什么（第一性原理）

> **企业变化已经发生，但市场认知和价格反映尚未完成的公司。**

投资机会存在于因果链的缺口窗口：

```
真实变化 ↑
    ↓
市场认知 ↓   ← 机会窗口在这里
    ↓
资金行为 ↓
    ↓
价格反映 ↓
```

系统不是"股票筛选器"（找最好的公司），而是**市场认知差探测器**（找变化已发生、认知未完成的公司）。

## 二、为什么市场会错（机制假设）

1. **信息到达不同步**：财报/订单/行业数据公开有时间差，部分变化只能从财务科目中推断（如合同负债先行）
2. **注意力稀缺**：5000 家公司，卖方覆盖集中在头部，中小盘变化被发现慢
3. **确认偏好**：机构倾向于等待"确认"（连续两季改善）才行动，错过拐点早期
4. **叙事滞后**：股价反映需要"故事"包装，财务变化先于叙事形成

## 三、投资假设清单（Phase 2 逐条验证）

### H0：三引擎互补（2026-09-01 新增，最高优先）

- **预测**: Discovery + Confirmation + Valuation 融合组合的 IC/分组收益 > 任一单独引擎
- **数据**: S1/S2（Discovery）× RPS（Confirmation）× PE 分位（Valuation）
- **验证**: 三引擎单跑 vs 融合的 IC / Rank IC / 分组收益 / 稳定性对照
- **失败标准**: 融合不优于单独 Confirmation → 保持现状（趋势确认型），不投入 Discovery 建设
- **定位**: 回答"要不要建设 Discovery Engine"——Baseline A 已证明 Confirmation 强，本假设决定下一步投入方向

### H1：认知差有效（核心假设）

- **预测**: 变化已发生（S1/S2 高分）但市场认知未完成（RPS 未过热 + 估值分位低）的组，未来 1/3/6/12 月超额收益 > 已确认组（RPS 高 + 估值分位高）
- **数据**: Growth Score（S1/S2）× RPS60 × PE 行业内分位
- **验证**: 3×3×3 分组收益（§五）
- **失败标准**: Early Discovery 组 6 月收益 ≤ Confirmed 组 → 认知差框架不成立，A 股可能是趋势确认主导 → 调整方向

### H2：周期拐点有效

- **预测**: 利润加速前期（S1 斜率刚转正、低基数过滤后）股票有超额收益
- **数据**: S1 / S2 / Growth OS lifecycle
- **验证**: S1 高分组的未来 6 月收益 + 单调性
- **失败标准**: S1 分组无单调性 → 利润加速是常见陷阱（低基数假象）

### H3：质量过滤有效

- **预测**: 同样周期机会中，高 ROIC / 正现金流公司风险调整收益更高（回撤更小）
- **数据**: ROIC-WACC / S5 / S7
- **验证**: 组内按质量分层比较最大回撤 / 收益
- **失败标准**: 高质量组无回撤优势 → 质量维度可降权

### H4：认知差是时变的

- **预测**: 认知差窗口长度随市场状态变化（牛市窗口短、熊市长）
- **数据**: Regime（BULL/STRUCT/BEAR）× 分组收益
- **验证**: 分 Regime 的分组收益对照
- **失败标准**: 窗口长度无差异 → 认知差与市场状态无关

## 四、Opportunity Lifecycle 状态机（研究池分层）

```
L0 变化未发生     行业弱 + 公司弱 + 无催化          → 忽略
L1 变化萌芽       订单/库存/利润拐点出现，市场未知   → ★★★★ 最高研究优先级
L2 市场开始发现    机构调研增加、股价突破、成交放大    → 机会减少
L3 一致预期形成    券商覆盖增加、估值提升、讨论爆发    → 风险增加
L4 兑现阶段       业绩兑现、估值完成                → 开始退出
L5 错杀恢复       逻辑没坏 + 短期事件下跌（黄金坑）  → 特殊机会（你的错杀恢复系统）
```

对应数据代理（Phase 3 完善）:
- L1: S1/S2 拐点 + RPS 低分位 + 估值分位低
- L2: RPS 中分位 + 成交放大（volume 数据已有）
- L3: RPS 高分位 + 估值分位高
- L5: 基本面未坏（S1/S2 仍正）+ 短期大跌（乖离率负向，需要修复 valuation_filter 数据源后可用）

## 五、3×3×3 认知差分组检验设计（Phase 2 核心）

| 维度 | 分组 | 代理 |
|---|---|---|
| 变化强度 | 低/中/高 | Growth Score（S1+S2 综合，三分位） |
| 市场认知 | 低/中/高 | RPS60（三分位）+ 成交相对历史（可选） |
| 估值压力 | 低/中/高 | PE 行业内分位（三分位） |

关键对比组：

| 组 | 变化 | 认知 | 估值 | 假设状态 |
|---|---|---|---|---|
| **Early Discovery** | 高 | 低 | 低 | 预期差最大（H1 预测收益最高） |
| Confirming | 高 | 中 | 中 | 确认中 |
| **Confirmed** | 高 | 高 | 高 | 已定价（H1 预测收益衰减） |
| No-Change | 低 | 任意 | 任意 | 无研究价值（对照） |

检验：Early Discovery vs Confirmed 的未来 1/3/6/12 月收益差 + 显著性（t 检验 + 样本量要求 n≥30/组）。

## 六、约束与原则

1. **假设先于编码**：Phase 2 验证通过前，不修改 composite 公式、不新增"认知差因子"到评分
2. **可证伪**：每个假设有明确失败标准，失败即修正框架（研究系统不是信仰系统）
3. **PIT 前提**：所有验证必须在 PIT 修复后的数据上进行（否则验证本身被污染）
4. **输出导向**：验证通过的假设 → 进入 Phase 3 Investment Memo 的"认知差状态"输出；验证失败的假设 → 从框架移除
