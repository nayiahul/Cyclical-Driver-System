**状态**: 设计稿（2026-09-01，等待 Gate 0-D 完成后定稿）
**目标**: 回答三个研究问题——排序有无信息量 / 哪些因子有贡献 / 研究池是否稳定
**定位**: 替代原"收益归因/Calmar 验收"，研究台视角的信号质量体检

## 一、回答的三个问题与对应指标

| 问题 | 指标 | 数据需求 |
|---|---|---|
| 1. 排序有没有信息量？ | 分组收益（Top10% vs Bottom10% 未来 1/3/6 月）+ 单调性 | 全量因子分数 + 未来收益 |

## 二、数据基础（需要在 B1/B 回测时同步输出）

### 2.1 因子分数存档（新增，扩展 audit）

每个调仓日 t 输出 `factor_scores/t_YYYYMMDD.csv`：

```csv
code,composite,rps,ind_mom,s1,s2,s5,s7,pe,val_ratio
000001,1.23,85.1,0.12,-0.5,0.8,1.1,0.9,23.5,0.72
...
```

来源：`compute_composite` 内部各信号字典（rps_scores / ind_scores / s1 / s2 / s5 / s7 / ttm_eps_map / pe_val）。
实现：engine 在调仓日已调用 compute_composite，在 audit_dir 分支内追加 dump（默认关闭，零开销）。

> 注意：audit 现有 score_hash 只能证明"分数没变"，不能用于分析——必须存全量分数本身。

### 2.2 未来收益计算

- 用本地 `STOCKS_DIR` 价格（前复权收盘）
- 未来 1/3/6 个月收益 = `close(t+k月首个交易日) / close(t) - 1`
- 用交易日历精确取 k 个月后的首个交易日，避免自然月差异
- 退市/停牌缺失 → 该样本标记 `missing_fwd` 计入覆盖率，不静默丢弃

### 2.3 观测窗口

- 调仓日：2022-02 ~ 2025-06（留出 6 个月未来收益窗口，2025-06 后不参与 6M 指标）
- 全量候选（~2000-3000 只/月），不是 Top100——分组收益需要完整分布

## 三、指标定义

### 3.1 Rank IC（Spearman）

```
对每个调仓日 t:
  ic_t = spearman(score_t, fwd_ret_t(k))

汇总:
  mean_IC(k) = mean(ic_t)         # k = 1/3/6 月
  IC_IR(k)   = mean(ic_t) / std(ic_t)
  IC>0 占比  = P(ic_t > 0)
```

分因子同样计算（composite / rps / ind_mom / s1 / s2 / s5 / s7 / pe）。

### 3.2 分组收益（十分位）

```
对每个调仓日 t:
  按 composite 分 10 组 (Q1 最优 … Q10 最差)
  每组平均未来收益 fwd_ret(k)

汇总:
  Q1 - Q10 价差（k = 1/3/6 月）
  Q1 > Q2 > … > Q10 的单调性（允许相邻倒挂，不允许 Q1 < Q5）
  Top10% 跑赢全市场等权比例
```

### 3.3 研究池稳定性

```
月度留存率(t) = |Top50(t-1) ∩ Top100(t)| / 50
连续 6 个月均值 = mean(留存率)

解读:
  > 40%  稳定，信号有持续性
  20-40% 中等
  < 20%  噪声大，研究池基本每月换血
```

## 四、验收对照（A vs B 是核心）

| 对照 | 内容 | 回答的问题 |
|---|---|---|
| A（污染基线） | 现有代码跑信号质量指标 | 当前研究池在"偷看未来"下有多强？ |
| B1（价格 PIT） | 修价格前视后跑 | 价格泄漏贡献了多少排序能力？ |
| B（财务 PIT） | 修披露日后跑 | 财务泄漏贡献了多少？ |
| 结论 | 若 B 的 Q1-Q10 价差/IC 显著低于 A | 原研究池优势部分是泄漏泡沫，必须用 B 后的信号做研究 |

**验收标准（研究台视角，非交易视角）**：

1. B 状态下 mean_IC(6M) > 0 且 IC>0 占比 > 55% → 排序有信息量（不设绝对 IC 门槛，A/B 对照 + 显著性检验为准）
2. B 状态下 Q1(6M) > Q10(6M)（价差 > 0）→ 分组单调性成立
3. B 状态下留存率 > 20% → 研究池不是纯噪声
4. 至少 2 个因子在 B 状态下 IC 显著 > 0 → 多因子不是摆设

> 全部指标输出 A/B1/B 三列对照表，若 B 显著劣于 A → 量化泄漏贡献，写进研究可信度报告。

### 4.1 核心检验：H1 认知差假设（见 INVESTMENT_HYPOTHESIS.md）

Phase 2 的第一任务不是验证"分数高是否涨"，而是检验系统第一性原理：

```
H1: 高变化 + 低认知 + 低估值（Early Discovery）
    > 高变化 + 高认知 + 高估值（Confirmed）
    未来 1/3/6/12 月收益
```

实现：
- 因子分数存档后，按 §五 3×3×3 分组（变化强度 S1+S2 / 认知 RPS / 估值 PE 分位）
- 输出 Early Discovery vs Confirmed vs No-Change 三组未来收益 + t 检验
- 结论决定后续：H1 成立 → Phase 3 Memo 输出认知差状态；H1 不成立 → 框架修正（可能 A 股趋势确认主导）

> 其余假设（H2 周期拐点 / H3 质量过滤 / H4 认知差时变）按 INVESTMENT_HYPOTHESIS.md 逐条验证。
