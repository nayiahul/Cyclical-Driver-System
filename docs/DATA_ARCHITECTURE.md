## 五、数据缺口路线图（按研究价值排序）

### P0（发现引擎依赖，Phase 3 前必须评估）
1. **预期数据**（一致预期 EPS 修正/盈利预测变化）——认知差框架的核心输入，"市场是否低估"的唯一直接证据
2. **Universe 历史化**（delist master + 历史 ST）——U1/U2，spike 后接入

### P1（增强 Confirmation / Valuation）
3. **资金行为数据**（北向/两融——margin_data.csv 已有两融余额，可先用；北向需新源）
4. **产业周期变量**（半导体库存/化工价差/新能源产能利用率——先做 3-4 个重点行业的手工维护表）

### P2（研究辅助）
5. **事件催化日历**（财报/解禁/分红/机构调研——disclosure_calendar 已有财报日，扩展解禁/调研）
6. **复权一致性验证**（抽样对比前复权/后复权对 RPS 的影响）

## 六、接入规则（防退化）

1. 任何新数据资产必须经 pit/ 契约层接入（禁止业务模块直读）
2. 新资产必须声明：来源 / 覆盖范围 / 刷新频率 / PIT 语义 / 已知限制
3. 新资产接入时同步更新本架构文档与 DATA_INVENTORY.md
4. 预期/另类数据接入前必须先定义其研究用途（不堆数据）
