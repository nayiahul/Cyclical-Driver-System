# Paradigm Layer v0 — 产业范式状态层设计规范（冻结）

**日期**: 2026-09-02（Step 11-C5）
**定位**: 可插拔产业解释层——不是选股模型，不是行业主题标签
**原则**: 防污染（P 不独立创造机会，只作为 L/E 的增强与验证路径）

---

## 一、三轴架构

```
            Paradigm Layer (P)
                  │
                  │ 解释: 为什么这个变化可能持续
                  ▼
Lifecycle (L) ──── Expectation (E)
  公司发生了什么       市场知道多少
                  │
                  ▼
           Research Priority
```

| 轴 | 回答 | 决定 |
|---|---|---|
| L | 公司发生了什么变化？ | 是否进入机会池（企业层筛选） |
| E | 市场知道多少？ | 机会池内的优先级（认知差窗口） |
| P | 为什么这个变化可能持续？ | 研究深度 + 验证路径（门控，非加分） |

## 二、禁止事项（防污染核心）

1. **不合并评分**: `Score = L×a + E×b + P×c` → 禁止（会变成主题投资）
2. **不突破 E 限制**: P 高不能把 E2/E3 升为 A 级（光迅/沪电 PE 分位 94-95% 即使 P2 也非预期差区）
3. **不扩大覆盖**: 新增研究池 <5%（防止 P 变成行业主题池）
4. **不自动扩展**: 新范式必须走完整验证链（异常→候选→整体→子类→人工→反事实）才能接入

## 三、P 状态定义（v0 通用框架）

| P | 名称 | 通用条件 |
|---|---|---|
| P0 | 无产业催化 | 普通成长，无范式驱动 |
| P1 | 产业需求出现 | 下游资本开支增长 + 订单开始改善 |
| P2 | 产业兑现阶段 | 连续季度订单 + 收入兑现 + 毛利保持 + 龙头验证 |
| P3 | 一致预期形成 | 估值扩张 + 机构覆盖增加 + 成交放大 |
| P4 | 产业过热 | 订单增速下降 + 库存增加 + 毛利下降 + 估值极端 |

## 五、L×E×P 机会矩阵（P 为门控）

| L×E | P1/P2（产业验证/兑现） | P3（一致预期） | P0（无催化） |
|---|---|---|---|
| **L1×E0/E1** | ⭐⭐⭐ 最佳 | ⚠️ 观察 | 普通 L1 |
| **L5×E0** | ⭐⭐⭐ 错杀+产业确认 | ⭐⭐ | 普通 L5 |
| L1×E2/E3 | ⚠️ 降级（已定价） | ❌ 禁区 | — |

**硬规则**: P 只能提升研究深度标签（A+ vs A），不能把 E2/E3 拉回 A 级。
