## 一、四象限分布

| 象限 | 占比 | n | 含义 |
|---|---|---|---|
| 未恢复 + 无超额（失败） | 39.8% | 612 | 真正失败 |
| **恢复 + 超额（理想）** | **26.6%** | 409 | 完美命中（状态+收益双确认） |

## 二、核心指标

```
Recovery Efficiency Ratio = 超额恢复 / 状态恢复 = 53%
```

**恢复的股票中 53% 产生超额收益**（R3 全样本 36.6% 被未恢复样本稀释——恢复是超额的必要前置）。

## 三、失败归因（未恢复 50%）

| 特征 | 比例 | 结论 |
|---|---|---|
| RPS 掉至 <30 | **62%** | "被遗忘"而非"暂时错杀" |
| RPS 继续下降 | 49% | 下跌趋势未止 |
| 范式 | 消费 51% / 周期 49% | 无范式偏向 |

**核心洞察**: 失败的 L5 大多是"市场关注彻底消失"的股票——不是错杀，是被遗忘。

## 四、"恢复但收益弱"（23.6%，最大改进空间）

行业 Top: 医药 80 / 机械 70 / 化工 47

**假设**: 状态恢复（R2✅）但涨幅有限（R3❌）→ 估值空间不足 或 盈利弹性弱 或 行业 Beta 弱。
**L5 v2 候选条件**: 恢复确认时 PE 分位仍低 + 行业 RPS 同步回升。

## 五、对 L5 v2 的设计指引

1. **Recovery Trigger 条件**: RPS 拐头（进入时 RPS 已止跌回升，非继续下跌）——直接对治 62% 被遗忘样本
2. **行业确认**: 行业 RPS 同步改善（恢复不是个股独行）
3. **估值确认**: 恢复时 PE 分位仍低（对治"恢复但收益弱"）
4. 三个条件不需要全过，2/3 即升级为 L5-A2（高置信恢复）
