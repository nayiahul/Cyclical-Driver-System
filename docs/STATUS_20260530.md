日期：20260530 | 版本：v3.0-stable + Growth Source v1.1 | 提交：75 次

## 系统架构

```
全A股 ~5000只
  → 预过滤器 (基础清洗 → 成长信号门4路径OR → 行业否决)
  → L1 排雷 (8条件红灯 + ROIC波动率周期检测)
  → L2-L5 六层漏斗 (L3 Sigmoid + 50/50 raw+rank + 2D范式权重)
  → 7 Regime 路由 + 6 行业范式
  → Top 20 候选池
  → Growth Source Engine (6维归因 + 仓位建议 + Cycle State)
  → output/growth_source_YYYYMMDD.md (归因卡片)
  → data/feedback/snapshot/YYYYMMDD.json (预测快照)
```

Composite 极差：14.0 (基线 10.0 → +4.0)

## 运行方式

### 1. 批量筛选 (日常)
```bash
source .venv/bin/activate
python -m growth_os.run_screen --top 20 --workers 8
```
输出: `output/growth_pool_YYYYMMDD.csv` + `output/growth_source_YYYYMMDD.md` + `data/feedback/snapshot/YYYYMMDD.json`

### 2. 个股体检
```bash
python -c "from growth_os.report import generate_report; generate_report('300308', '20260530')"
```
