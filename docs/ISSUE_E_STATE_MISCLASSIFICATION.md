# Issue: E-State Misclassification — E 层把"价格弱"误当"认知低"

**发现日期**: 2026-09-02（用户质疑 300308 触发）
**类型**: Expectation Layer 定义错误（系统最重要的一类模型错误）
**影响**: AI 龙头/白马成长/大牛股回撤 全部被误标 E0

---

## 一、错误映射（当前实现）

```
RPS 低（60日动量弱）
    ↓
E0 市场忽略
```

**错误根源**: RPS 是"价格动量"指标，不是"关注度/认知"指标。

## 三、两种"RPS 低"是相反的投资情景

| | A. 真忽略 | B. 高关注回调 |
|---|---|---|
| 成交额 | 低（11亿级） | 高（100亿+，恐慌/分歧） |
| 历史涨幅 | 无 | 巨大（+100%~300%） |
| 认知状态 | 市场不知道 | 市场知道，意见分裂 |
| 投资含义 | 预期差：新变化没人发现 | 高预期资产的重新定价（是过度悲观还是见顶？） |
| 研究问题 | "为什么没人发现？" | "市场是否过度悲观？" |

## 四、E 状态 v2 设计（三分层）

```
E = Attention（市场看没看到）
  + Expectation（市场相信多少）
  + Price State（价格在什么位置）
```

### 修正规则（v2 候选）
```
E0 真忽略 必须同时满足:
  RPS 低
  + 成交额低（相对自身历史 <0.5x 或绝对低）
  + 历史无大涨（12月涨幅 < 50%）
  + 历史 RPS 峰值低（从未高关注）

E5 高关注回调 当:
  历史涨幅大（>100%）或 历史RPS峰值高（>80）
  + 当前 RPS 低
  + 成交额高（分歧/抛售）
  → 研究问题不同: "是否过度悲观" (类似 L5 但原因不同)

E4 高预期消化 当:
  历史大涨 + 估值分位仍高（>70%）
```

## 五、对 300308 的正确标签（修正后）

```
不是: L0 × E0（市场遗漏）
而是: L1(强变化) × Attention HIGH × Price CORRECTION(-38%)
研究问题: 市场已发现，但是否过度悲观？（高预期二次机会 vs 见顶）
```
