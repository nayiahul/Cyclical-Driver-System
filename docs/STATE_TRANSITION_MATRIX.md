## 三、用途

1. **研究优先级**: P(下一状态) 决定优先级，而非当前状态
   - L1: 46% 升级 → 跟踪
   - L5: 25% 恢复 → 研究
   - L3: 17% 崩塌 → 警惕
2. **状态机 v3 输入**: 迁移概率作为"恢复 Trigger"的基准（L5 + 触发条件后迁移概率应显著高于 25.1% 基线）
3. **L5 v2 验收基准**: Recovery Trigger 的目标 = 把 L5→L2/L3 从 50.2%（v2 实测）提升到更高
