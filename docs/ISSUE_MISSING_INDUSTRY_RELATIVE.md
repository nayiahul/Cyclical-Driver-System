# Issue: Missing Industry-Relative Layer (L-relative 缺失)

**发现日期**: 2026-09-03（恒瑞案例行业对照触发）
**类型**: L 层定义缺陷——L 只判断"公司自身绝对变化"，缺"公司相对行业变化"
**状态**: Issue 记录 → T+30 评估（运行期不修复）

---

## 一、案例（600276 恒瑞 → 多层校准失败）

| 层 | 系统判断 | 数据核验 |
|---|---|---|
| L1 探针 | 合同负债 +371% → 订单爆发 | 低基数: QoQ -35% (14.5→9.5亿) |
| 结果验证 | (未检查) | 营收 +13%→-1.9% 转负; 扣非 -12.7% |
| 行业基准 | (未检查) | 行业营收中位 +1.5%(改善中), 恒瑞 -1.9% → **跑输行业** |

## 二、三层错误链（非单一缺陷）

1. **低基数偏差**: YoY 无 QoQ/绝对规模过滤
2. **信号背离**: 领先指标↑(合同负债同比) + 结果指标↓(收入/扣非)——未验证
3. **行业相对缺失**: 单看恒瑞"恶化"或"改善"都无意义, 需相对行业位置

## 三、L-relative 设计（v4 候选）

以后所有 L1 信号必须三角验证:
```
            行业
             ▲
             |
公司历史 ◄──── 公司当前
```

新增维度:
- L-abs: 公司绝对经营状态 (现 L 层)
- L-rel: 行业相对排名 (营收yoy/扣非yoy 的行业中位数偏离)
- L-trend: 自身趋势 (QoQ 方向)

新 L1 强信号六条件 (v4 候选):
① YoY增长 ② QoQ不下降 ③ 合同负债/收入占比提高
④ 收入趋势未恶化 ⑤ 扣非未明显恶化 ⑥ 行业排名不落后
